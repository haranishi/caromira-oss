# カロミラー

このOSS版は学習・研究用の試作品です。予測の実測精度と安全性は未検証で、食事制限・治療・栄養指導の判断には使わないでください。
新規履歴のソース公開であり、サービスのデプロイや本番設定の変更は行っていません。
自作ソースは [MIT](LICENSE)、人体モデルは [CC0・出典](public/models/CREDITS.md) です。依存ライブラリ・商標はそれぞれの条件に従います。

現在の体格と摂取カロリーから将来の体重・体脂肪率を幅で予測し、回転できる3D体型で見せるシミュレーターです。食事の選択が将来の体型へどうつながるかを理解し、体脂肪率の目標を検討するための試作です。

## 目的

- カロリー収支を体重の数字だけでなく、未来の体型イメージへ翻訳する
- 現在から365日後までを動かし、継続した食事条件による変化を比較する
- 目標体脂肪率から、目標体重・期間・摂取カロリーの目安を逆算する
- 過度な目標には安全性の警告を出す

## 予測モデルの判断

- BMRには性別・体重・身長・年齢を使う Mifflin-St Jeor式を採用している
- TDEEはBMRへ5段階の活動係数を掛けて算出する
- 長期予測で変化を過大評価しやすい `7,700 kcal = 1 kg` の線形則を本予測には使わず、約1年で定常変化の50%へ近づく単一指数の近似を使う
- 食事制限に対する現実の変化を一点で断定せず、モデル変化量の60〜95%を予測幅として返す
- 体重変化に伴う脂肪量と除脂肪量の配分はForbes則で推定する
- 体脂肪率は測定誤差より細かく見せず、男女別の5段階へ丸めて体型表現へ接続する

## 安全性と制約

- 予測値は目安であり、医療・栄養の専門的助言や個人の診断を目的としない
- 目標体脂肪率が必須脂肪域未満、または目標BMIが18.5未満になる場合は目標設定不可とする
- 摂取カロリーの下限は男性1,500 kcal/日、女性1,200 kcal/日としている
- 目標期間は週あたり現体重の0.75%変化を安全ペースとして逆算する
- 活動係数、安全域、現実補正幅は固定値で、実測データによる個人別補正は行わない
- コード内にも明記されているとおり、安全域の国内一次資料による裏取りと予測幅のキャリブレーションは未完了である

## 3D表示の設計

- Three.jsとReact Three Fiberを使い、WebGL対応ブラウザの端末上で描画する
- 体脂肪率を男女別の範囲から0〜1へ変換し、胴回りと腹部を連続的に変形させる
- 外部の画像生成APIは使わず、Blender Studio Human Base Meshes由来のCC0モデルを加工して表示する
- 3D表示はサーバーサイドレンダリングせず、クライアントでのみ読み込む

## 未完了・触る際の注意

- 現在の3D人体は加工した汎用メッシュで、実在人物の体型再現や医学的な人体モデルではない
- 自撮りから本人に近い顔を端末内で合成する構想は画面文言だけで、実装されていない
- より精密なNIH Body Weight Planner相当のモデル、2時定数モデル、食事・運動による体組成補正は未実装
- `AvatarSilhouette` は3D表示以前の簡易SVG表現として残っているが、現在の画面からは使われていない
- 宅食・プロテインへの送客枠は将来予定を示す文言だけで、リンクや連携はない
- 入力値の永続化、履歴比較、ログイン、バックエンド、外部API連携はない
- 予測エンジンのデモはあるが、自動テスト環境と `tsx` の依存関係は用意されていない
- エンジン内のコメントが参照する要件定義の節や出典一覧は、このリポジトリには含まれていない
- 体脂肪率や期間の範囲、安全定数を変えると、予測・警告・3D段階の整合性が崩れるため同時に見直す必要がある

## 動作条件

Node.js環境とWebGL対応ブラウザが必要です。

```bash
npm install
npm run dev
```
