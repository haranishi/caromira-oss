# 設計: 依存関係のセキュリティ更新

## 2026-10-22の対応（履歴）

## 方針

- `package.json` の `next` を 16.2.10 から `16.4.2` にする。ソースは変更しない。
- Next.js 自身の依存が上がる分に加え、更新後の再照合で残った、範囲内で直せる部品は `npm update` で上げる。

## 検討して見送った案

- `eslint-config-next` も上げる: 同梱のルールが変わり、lint の指摘が増えるおそれがある。今回の目的に不要なため見送り。

## 影響

- 変更ファイル: `package.json`（1 行）・`package-lock.json`。
- 上がった版:

| パッケージ | 更新前 | 更新後 |
|---|---|---|
| next | 16.2.10 | 16.4.2 |
| sharp | 0.34.5 | 0.35.5 |
| postcss | 8.5.16 | 8.5.23 |
| nanoid | 3.3.15 | 3.3.20 |
| source-map-js | 1.2.1 | 1.2.2 |
| baseline-browser-mapping | 2.10.42 | 2.11.30 |

## 2026-10-30の追加設計

brace-expansion・browserslist・js-yaml・PostCSS等の警告対象を宣言範囲内の修正版へ更新する。
親が古い版を固定する場合は、必要な親の互換更新を含めて解消する。
無関係なeslintルール・React・Nextの変更や、DB・本番設定への変更を含めない。
lockfile再現導入、型・lint・本番ビルドで互換性を確かめる。
