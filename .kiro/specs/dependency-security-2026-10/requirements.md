# 要件: 依存関係の既知の脆弱性を解消する（caromira-oss）

## 背景

- 2026-10-22 の点検で、このリポジトリの Next.js 16.2.10 に既知の脆弱性が 17 件あった（GitHub 公式の脆弱性データベースで重大 3・高 5・中 8・低 1）。
- 静的書き出し（`output: "export"`）のため、Next のサーバー側の勧告は、書き出した静的ファイルには及ばない。このリポジトリ自体も公開先を持たない試作の公開ソース。
- 複製して使う人が古い版を入れないよう、最新の安全な版に更新する。公開中の最新版 Next.js 16.4.2 は既知の脆弱性が 0 件。

## 要件

1. システムは、Next.js を既知の脆弱性が 0 件の版（16.4.2）で動かさなければならない。
2. 本番側（実行時）の依存に、既知の脆弱性を残してはならない。
3. 画面と機能の挙動を変えてはならない。更新前に成功していた検証は、更新後も成功すること。
4. 更新前から失敗している検証は、悪化させないこと。更新前から失敗しているもの:
- `npm run lint` のエラー1件（更新前から）

## 2026-10-22の範囲外（履歴）

- 機能追加、デザイン変更、開発用ツール（eslint など）の更新。

## 2026-10-30の追加要件

全所有リポジトリの安全化依頼に合わせ、開発依存の既知の脆弱性も修正対象とする。
Next.js 16.4.2と既存の画面・機能・ライセンスを維持し、警告対象を互換修正版へ更新する。
元から失敗する検証は更新前後で区別し、新しい失敗を持ち込まない。
